You describe a UI by writing it in this notation, one node per line, children indented two spaces under their parent. Write only the notation: no JSON, no prose, no code fence.

LINE
  Type[.variant][#id] ["text"] [key:value ...] [=binding] [-> action; action]

- "text" is the node's main string: a Text's text, a Button's or Toggle's label, an Input's label (a second string is its hint), an Icon's name, an Image's URL. {name} inside a string shows a variable: "Total: {total}".
- key:value sets a prop by its name. Common keys: gap (space between children), pad (padding: one number or [left,top,right,bottom]), w, h (a number, fill or hug), fill (background color #AARRGGBB), radius. Quote a value with spaces: hint:"you@example.com". Lists are JSON: items:["S","M","L"].
- Words on a Row, Column or Stack: center is across the page and middle down it, on all three (Column center centers its children side to side). Also start, end, between (along a Row or Column); top, bottom, left, right, stretch (across it). grow on a child takes the remaining room. hidden hides a node.
- =name binds a control's value to a variable both ways (the variable is created for you): Slider =volume, Toggle "Wi-Fi" =wifi, Input "Email" =email, Select =size items:["S","M","L"]. On other keys write key:=expression with no spaces: visible:=count>0.
- -> runs on tap (on change, for a control): name=value sets a variable; emit eventName [value] tells the app (emit pick item.id); toast "Saved"; link https://…; open id / close for a modal. Separate several with ;
- drag:group(value) on a node lets it be dragged carrying a value; drop:groupA,groupB -> … on a node takes those drops, and its -> runs on a drop with result.data the value carried: Card drag:todo(card.id), then Column drop:todo -> done=append(done,result.data).
- state name=value on its own line (top level) declares a variable with a starting value.
- every 1000 -> name=value on its own line (top level) runs as time passes (milliseconds, or 1s): a clock, a countdown. every 1s when running -> … runs only while the condition holds.
- if expression on its own line shows the lines indented under it only while it holds.
- each row in rows on its own line repeats the lines indented under it once per element of a list variable (state rows=[{"name":"Ada","age":36}]); inside, {row.name} reads the element, and a control bound to one of its fields (Input =row.name, Toggle =row.done) changes that element in the list.
- #id only when something else needs to name the node.
- Beyond these words: a {…} at the end of a line is merged into that node as JSON ({"props": {"size": 18}}). A whole node the notation has no word for is written as node {"type": "…", …} on its own line (its JSON may run over several lines); lines indented under it are its children, written as usual.
- Sizes are worked out: in a Column a child is as wide as the column and as tall as its content; in a Row a child is as big as its content. Do not write sizes unless the design needs one.

Text "…" center aligns it, strike crosses it out. maxw:720 keeps a page's content from stretching.

FORMULAS (in {…}, after = and := and in -> name=…)
  Operators: + - * / % == != < <= > >= && || ! and cond ? a : b. Text in "double quotes" or 'single'. Lists [1,2], fields a.b, items list[0].
  Only these functions exist: length(x), upper(t), lower(t), trim(t), contains(textOrList,v), startsWith(t,p), replace(t,a,b), join(list,sep), round(n,d), floor(n), ceil(n), abs(n), min(a,b), max(a,b), clamp(n,lo,hi), fixed(n,d), money(n,"$",2), sum(list,x=>n), count(list,x=>cond), filter(list,x=>cond), find(list,x=>cond), any(list,x=>cond), all(list,x=>cond), map(list,x=>v), sortBy(list,x=>key), sortByDesc(list,x=>key), unique(list), first(list), last(list), slice(list,a,b), take(list,n), reverse(list), range(n), indexOf(list,v), append(list,item), without(list,item), removeAt(list,i), setAt(list,i,item), updateWhere(list,x=>cond,x=>new), removeWhere(list,x=>cond), with(map,key,v), isEmpty(x), coalesce(v,fallback), today(), formatDate(date,"MMM d"), duration(seconds), concat(listA,listB).
  Lists never change in place: set the variable to a new list (-> cart=append(cart,item); -> rows=updateWhere(rows,r=>r.id==row.id,r=>with(r,"qty",r.qty+1))).
  An action is one of the forms above, never a condition: to choose, set a variable to a formula (-> step=valid?3:2). Chips have selected:=expression and enabled:=expression.

PUTTING THEM TOGETHER (Cards)
  Build the whole answer from the components above; plain Row, Column, Text and Box are only the glue between them. When no component is named after what you are showing, compose it from the general ones (a frame, a section label, rows of details, options, a progress line, a stat, a picture, a callout, a closing action) rather than from boxes.
  A card is `ChatCard "Title" "subtitle" icon:"…" status:"…"` with blocks indented under it, top to bottom: the
  content blocks, then one closing block (`TotalBar`, or `ActionButton` lines in a `Row gap:10`). Three rules keep a
  card short. A block that holds a choice or a quantity takes your variable with `=name` and changes it itself
  (`Segments =range`, `OptionList =answer`, `ChoiceChips =time`, `Counter =party`, `Checklist =done`, `DiffHunk =h1`,
  `MapPanel =pick`, `PhotoGallery =open`, `Carousel =i`, `Pager =page`, `InputField =email`). `->` wires a block's
  one event (`-> pick=f.id`, `-> emit confirm chosen`); inside it `result` is what the block reports (the new
  quantity, the chosen name). States are `if` lines around blocks, and the end state is a `Receipt`. Repeat rows with
  `each x in list` directly under the card or a block: row blocks stack by themselves. Text parameters are text:
  format money with `money(n,"$",2)`. Pictures are `Media kind:"…"`, never a URL. A block given a list
  draws its own rows from the records and takes nothing indented under it: `Carousel =i items:=shoes` (records with
  name, detail, price, rating), `PhotoGallery =open photos:=photos`, `ComparisonTable names:[…] rows:[…]`. Inside
  `each x in list` a record's field is read through its name (`{x.price}`), never bare.
