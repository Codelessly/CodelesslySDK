Website layout: a 12-column feel on a 1120 rail. Every band shares one gutter (32 px at tablet, 48 px from 1024) with its content capped and centered, so the nav, hero, plans, table, FAQ and footer all start on the same line.

- **Hero and plans:** the hero is a centered column (title capped at 720) above three plans side by side. Team is set apart by a blue border, an accent "Most popular" badge and the only filled button.
- **Billing switch:** a neutral segmented control whose selected side gets a white fill and a blue border. It flips every price, billing note and comparison header at once.
- **Comparison table:** a real table card with a two-fifths label column and three plan columns, built from one row template and one cell template.
- **FAQ:** a desktop two-column split, the intro on the left and the questions on the right, which stacks below 900 px.
- **At 768:** nav links hide, plans stack in a 460 px column, and the FAQ split becomes vertical.

MISSING TOKENS
- displayTitle: Inter Display 54 / 800, height 1.06, letterSpacing -1.8 (42 below 900 px). Used for the hero title; the theme's largest title (titleWide 28) is a card size, not a page headline.
- sectionHeadline: Inter Display 32 / 700, height 1.15, letterSpacing -0.8. Used for "Compare plans" and "Frequently asked questions".
- leadLarge: Inter 17 / 400, height 1.55. Used for the hero paragraph under the title; the theme's `lead` (14) is too small for a page intro.
- priceDisplay: Inter Display 46 / 800, height 1.0, letterSpacing -1.6. Used for plan prices; numberLarge (30) is too small and numberHero (56) too large for a three-across card.
- radius.pageCard: 18. Used for the plan cards and the comparison card. The theme's `card` radius (26) is too round for desktop surfaces this size, so I used the `panel` value.
- spacing.gutter: 32 at tablet, 48 from 1024. Used as the side padding of every band.
- spacing.section: 56–96 vertical (hero 72/88 top, compare 56/72 top, FAQ 72/96 bottom). Used between page sections; the theme's spacing stops at 64 and has no section rhythm.
- layout.rail: 1120 max width. Used for every band's content.
- layout.measure: 720 for the title, 560 for the hero lead, 620 for the comparison subtitle. Used as readable text widths.
- shadow.pageCard: #0A000000, offset 0 6, blur 20. Used for the plan cards, written literally because a theme shadow can't be bound per item here.
- control.navButton height: 38, and the plan button height 46. Used for the nav CTA and plan CTAs; there is no height token for controls.
- color: none missing.
