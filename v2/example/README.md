# Codelessly SDK v2 example

Shows published Codelessly projects, migrated from v1, with the v2 SDK. The
publish bundles in `assets/` are built by
`CodelesslyAPI/v2/migrate/bin/publish_fixture.dart`.

    flutter run -d chrome    # or -d linux / macos / windows

Resize the window to see each screen pick its mobile, tablet or desktop
canvas; taps on tabs and buttons navigate between screens. The menu at the
bottom right switches project.
