From 10.x (v1) to 20.x (v2)
A rewrite: a new project format, a new renderer, a smaller and more explicit API.
10.x
  • v1 documents
  • A widget tree per node
  • A global Codelessly.instance
  • Firebase always initialized
  • BaseNode classes
  • layoutID
20.x
  • "schema": 2
  • Render objects, one box per node
  • Explicit instances; a default only if you set one
  • Firebase only with firebase.dart
  • Node, WidgetSpec, total decoding
  • layoutId
Neither version reads the other's format. Dart 3.12 and Flutter 3.35 or newer.
Update the dependency
dependencies: codelessly_sdk: ^20.1.0
Also
codelessly_api, if you depend on it directly: ^20.0.0. Apps with scripts keep codelessly_quickjs.
Initialization
10.x Codelessly.instance.initialize( config: const CodelesslyConfig(authToken: authToken, isPreview: kDebugMode), ); runApp(MaterialApp(home: CodelesslyWidget(layoutID: layoutID))); 20.x import 'package:codelessly_sdk/codelessly_sdk.dart'; import 'package:codelessly_sdk/firebase.dart'; final codelessly = await codelesslyWithToken( authToken, config: const CodelesslyConfig( publishSource: kDebugMode ? PublishSource.preview : PublishSource.publish, ), ); Codelessly.setDefault(codelessly); // only if you want widgets to find it without being given it runApp(MaterialApp(home: CodelesslyWidget(layoutId: layoutId)));
API changes, for example functions
10.x functions: { 'onNextButtonClicked': CodelesslyFunction((context, reference, params) { Navigator.of(context).pushNamed('/next'); }), } 20.x CodelesslyConfig( functions: { 'onNextButtonClicked': (context, params) { navigatorKey.currentState!.pushNamed('/next'); // a GlobalKey<NavigatorState> of your app return null; }, }, )
