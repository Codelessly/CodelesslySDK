Drive the screen through a controller
// A value of the screen. expect(controller.read('count'), 1); expect(controller.read('route.id'), '42'); // A node as rendered: bindings and conditions applied. expect(controller.node('title')!.prop(TextProps.text), 'Hello, Ada!'); expect(controller.node('badge')!.visible, isFalse); await controller.trigger('button', 'click'); await frames(tester);
A chain that pushes a screen completes when that screen is popped: don't await trigger then.
Pump frames by hand
/// Screens with looping animations never settle: pump a second of frames. Future<void> frames(WidgetTester tester) async { for (var i = 0; i < 10; i++) { await tester.pump(const Duration(milliseconds: 100)); } }
