Load by slug (above), by project token, or offline from a bundle: one line changes, the widget stays the same.
Install the SDK
$ flutter pub add codelessly_sdk
Requires
Dart 3.12
Flutter 3.35
or newer
The SDK exports the model (codelessly_api), so most apps need only this one package.
Then copy one of these
Both are under Publish & integrate in the Editor.
Web tab: the slug
Embed in Flutter tab: the SDK token
No slug or token yet? The example app in example runs offline.
A. By slug
import 'package:codelessly_sdk/codelessly_sdk.dart'; import 'package:flutter/material.dart'; void main() { final codelessly = Codelessly(config: const CodelesslyConfig(slug: 'my-project')); runApp(MaterialApp(home: CodelesslyWidget(codelessly: codelessly))); }
Network
One HTTP request fetches the whole publish.
Firebase
None.
New publishes
On the app's next start.
B. By project token
import 'package:codelessly_sdk/codelessly_sdk.dart'; import 'package:codelessly_sdk/firebase.dart'; import 'package:flutter/material.dart'; Future<void> main() async { WidgetsFlutterBinding.ensureInitialized(); final codelessly = await codelesslyWithToken('YOUR_PROJECT_TOKEN'); runApp(MaterialApp(home: CodelesslyWidget(codelessly: codelessly))); }
Firebase
Set up for you: no google-services.json.
New publishes
Reach the running app live.
Not on Linux
Firebase has no Linux support: use a slug or a bundle.
C. Offline, from a bundle
# pubspec.yaml flutter: assets: - assets/my_project.json.gz
No network for the project
The bundle is the whole publish in one JSON file (gzipped or not).
void main() { final codelessly = Codelessly.asset('assets/my_project.json.gz'); runApp(MaterialApp(home: CodelesslyWidget(codelessly: codelessly))); }
Images, icons and web fonts still load from their URLs.

$ flutter run
