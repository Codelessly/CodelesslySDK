Codelessly cloud data, accounts and files
With a project token, one flag sets them up, under the project, in Codelessly's Firebase.
final codelessly = await codelesslyWithToken('YOUR_PROJECT_TOKEN', cloudServices: true);
Cloud data
Firestore, under data/{projectId}. Data rules followed live.
Accounts
Firebase Auth: email and password, email links, Google, Apple.
Files
Firebase Storage, under data/{projectId}.
Slug mode has no cloud services by itself. Build them with codelesslyCloudServices (it needs the project id), or use a token.
HTTP APIs on the web: CORS and a proxy
An API that doesn't allow your origin fails in the browser. Give the service a proxy you host.
