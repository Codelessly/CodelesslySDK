Formula, action or script?
Start with a formula. Use actions for what happens, in order. Reach for a script for logic with steps.
Formula
${= price * qty}
Runs whenever what it reads changes.
Changes the app never: it computes a value.
Text, colors, visibility, totals, filtering, formatting
Action
click → setVariable → callApi
Runs when its trigger fires, in order.
Changes the app yes.
Flow: what happens on a tap, in what order
Script
JavaScript in a sandbox
Runs from a "Run script" action, or script.name() in a formula.
Changes the app with granted capabilities.
Logic with steps, branches or loops
Adding the engine to your app
The SDK finds it when a script first runs. You don't import it.

Host APIs need capabilities
No network, files, timers, storage or DOM. Calling a host API without its capability throws a CapabilityError.
The sandbox
const r = await app.callApi("Weather", { city }); vars.set("forecast", r.body.daily.slice(0, 5)); await app.toast("Updated");
